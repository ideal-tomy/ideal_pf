# 体験版リンクのある詳細ページ：展開記録

確認日：2026-09-13

## 今回の範囲

ユーザーの最新指示に従い、availableかつ有効なHTTPS URLを持つ21件だけに建設の共通テンプレートを適用。preparingの7件は対象外で、従来の詳細描画を維持。全28件展開PLANのうち、リンクのあるページの展開を完了した記録。

## 実装

- src/demo-story.js：共通描画、建設原稿の変換、状態判定、外部CTA、画像・図解、開閉項目。
- src/demo-stories.js：建設以外20件の個別タイトル、概要、比較、見どころ見出し、自社への問い。小規模な静的サイトのため原稿を1ファイルに集約。
- src/story-images.js：新規取得した公開画面の画像とキャプション。
- src/construction-story.js：資料向け原稿exportを維持し、専用描画は共通描画に移行。
- src/main.js：対象21件のみ新描画、幅、背景操作抑制、一覧復帰、フォーカス循環を適用。
- src/style.css：共通クラスと業種別アクセント、最大400pxの画像、図解、画像読み込み失敗時の表示。

## 情報の保持

- whenは「どんな業務の悩みに役立つ？」へ全文保持。leadと対象者も同じ開閉項目に保持。
- canは見どころ本文へ全項目を保持。見出しは本文に対応する短い表現へ個別編集。
- experienceNoteは「体験について」で全文を常時表示。削除済みの冒頭補足を復活させず、必要な条件をこちらへ集約。
- plannedは元データを変更せず維持。機能未対応や保存範囲等は必要に応じて公開用の補足に記載。README更新、ドメイン整理等の内部TODOは公開本文へ追加しない。
- 原稿保持は20件のwhen/can/experienceNoteを共通描画HTMLと照合して確認。建設は元の原稿データと操作手順・条件を共通描画へ移した。

## 画像の確認範囲

画像登録済み5件は15枚を目視確認して再利用。建設の報告書は下書き完成後ではなくサンプル選択の入口の画像であるため、補足を実際の表示へ合わせた。

残り16件は公開入口がHTTP 200で表示できることを確認し、入口画像を取得。さらに画面切り替えリンクで開けた18画面を追加取得。録音、質問送信、外部通知、保存、送金等は実行していない。機能の一連の完走確認ではなく、公開入口と画面切り替えの確認。取得元のテキストとURLはsource-audit.json / navigation-audit.jsonに記録。

実画像のないプレビューは「機能のイメージ」と明示した図解を採用。入力や録音の結果画面、未撮影の判断結果を実画面のように作らず、既存の掲載情報に基づいた確認項目を示す。3ロールのタブは今回の取得処理では操作対象を特定できなかったため、入口画像と役割の図解を掲載。追加画像は該当の結果・役割画面を確認して取得できた時点で差し替える。
